# JMX support

> [!NOTE]
> JMX support has been removed in 5.0.
>
> We recommend switching to Spring Boot [Actuator Endpoints](https://docs.spring.io/spring-boot/reference/actuator/endpoints.html) and expose those over JMX if needed.
