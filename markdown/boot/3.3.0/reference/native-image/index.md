# GraalVM Native Image Support

[GraalVM Native Images](https://www.graalvm.org/native-image/) are standalone executables that can be generated by processing compiled Java applications ahead-of-time.
Native Images generally have a smaller memory footprint and start faster than their JVM counterparts.
