# Installing the CLI

The Spring Boot CLI (Command-Line Interface) can be installed manually by using SDKMAN! (the SDK Manager) or by using Homebrew or MacPorts if you are an OSX user.
See [*Installing the Spring Boot CLI*](../installing.md#getting-started.installing.cli) in the “Getting started” section for comprehensive installation instructions.
