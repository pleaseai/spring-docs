# JPA

This chapter points out the specialties for repository support for JPA.
Before continuing to the JPA specifics, make sure you have a sound understanding of the basic concepts explained in [Working with Spring Data Repositories](repositories/core-concepts.md).

The goal of the Spring Data repository abstraction is to significantly reduce the amount of boilerplate code required to implement data access layers for various persistence stores.
