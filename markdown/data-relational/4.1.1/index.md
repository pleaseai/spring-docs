# Spring Data JDBC and R2DBC

*Spring Data JDBC and R2DBC provide repository support for the Java Database Connectivity (JDBC) respective Reactive Relational Database Connectivity (R2DBC) APIs.
It eases development of applications with a consistent programming model that need to access SQL data sources.*
