# Spring MVC Test Integration

Spring Security provides comprehensive integration with [Spring MVC Test](https://docs.spring.io/spring-framework/reference/7.0.8/testing/mockmvc.html)

To begin using Spring Security’s MockMvc integration, you’ll first need to
[configure MockMvc](setup.md#test-mockmvc-setup),
and then you’ll be able to use Security’s
[RequestPostProcessors](request-post-processors.md)
and other MockMvc test support.
