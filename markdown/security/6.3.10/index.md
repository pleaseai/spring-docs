# Spring Security

> [!NOTE]
> Spring Security’s documentation can be [downloaded](https://docs.spring.io/spring-security/reference/spring-security-docs.zip) as a zip file.

Spring Security is a framework that provides [authentication](features/authentication/index.md), [authorization](features/authorization/index.md), and [protection against common attacks](features/exploits/index.md).
With first class support for securing both [imperative](servlet/index.md) and [reactive](reactive/index.md) applications, it is the de-facto standard for securing Spring-based applications.

For a complete list of features, see the [Features](features/index.md) section of the reference.

<a id="_getting_started"></a>

## Getting Started

If you are ready to start securing an application see the Getting Started sections for [servlet](servlet/getting-started.md) and [reactive](reactive/getting-started.md). These sections will walk you through creating your first Spring Security applications.

If you want to understand how Spring Security works, you can refer to the [Architecture](servlet/architecture.md) section.

If you have any questions, there is a wonderful [community](community.md) that would love to help you!
