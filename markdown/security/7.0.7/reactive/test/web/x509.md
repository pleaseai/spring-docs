# X509

Spring Framework provides first class support for testing X509 with `WebTestClient`.
For details refer to [`UserWebTestClientConfigurer`](https://docs.spring.io/spring-framework/docs/7.0.9/javadoc-api/org/springframework/test/web/reactive/server/UserWebTestClientConfigurer.html).
