# PasswordEncoder

Spring Security’s servlet support includes storing passwords securely by integrating with [`PasswordEncoder`](../../../features/authentication/password-storage.md#authentication-password-storage).
You can customize the `PasswordEncoder` implementation used by Spring Security by [exposing a `PasswordEncoder` Bean](../../../features/authentication/password-storage.md#authentication-password-storage-configuration).
