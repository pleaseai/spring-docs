# Repositories

This chapter explains the basic foundations of Spring Data repositories and Cassandra specifics.
Before continuing to the Cassandra specifics, make sure you have a sound understanding of the basic concepts explained in [Working with Spring Data Repositories](repositories/core-concepts.md).

The goal of the Spring Data repository abstraction is to significantly reduce the amount of boilerplate code required to implement data access layers for various persistence stores.
